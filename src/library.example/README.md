# library.example

The example library shipped by
[dotnet-template](https://github.com/mxwlf/dotnet-template), a baseline .NET
repository template. It exists to give the template something real to build, test,
pack and generate an SBOM for — replace it with your own library.

This file is the package readme, referenced by `PackageReadmeFile` in
`library.example.csproj` and packed by the `None` item next to it. It is
deliberately separate from the repository README, which documents the template's
make targets and CI wiring and would tell you nothing useful about this package.

## Usage

```csharp
using Library.Example;
```
